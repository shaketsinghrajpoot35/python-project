# Modern Static Project

A simple, yet stunning static web project featuring modern design aesthetics like **glassmorphism**, vibrant background glows, smooth typography, and subtle micro-animations.

## 🚀 Features

- **Glassmorphism Design:** Beautiful translucent panels that blend with the background.
- **Dynamic Backgrounds:** Floating, glowing background elements built purely with CSS.
- **Micro-Animations:** Interactive elements that respond to user clicks and hovers.
- **Responsive Layout:** Works great on desktop and adapts beautifully to different screen sizes.

## 🛠️ Technologies Used

- **HTML5:** Clean, semantic structure.
- **CSS3:** Advanced styling, CSS variables, keyframe animations, and flexbox/grid.
- **JavaScript (Vanilla):** Event listeners, dynamic styling, and DOM manipulation without any external libraries.

## 🏃‍♂️ How to Run Locally

Since this is a fully static project with no external dependencies, running it is extremely simple:

1. Clone the repository:
   ```bash
   git clone https://github.com/shaketsinghrajpoot35/python-project.git
   ```
2. Navigate to the project folder:
   ```bash
   cd python-project
   ```
3. Open the `index.html` file in your preferred web browser. You can simply double-click the file in your file explorer!
